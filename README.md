# Лендинг Никиты Морозика

Next.js-проект для лендинга на основе исходного прототипа в `prototype/`. Требования и решения хранятся в `instructions/`.

## Локальная разработка

Требуется Node.js 20.9+ и npm. Установите зависимости командой `npm ci`, затем запустите `npm run dev`.

Проверки: `npm run lint`, `npm run typecheck`, `npm run build`, `npm test`, `npm run test:e2e`. Для первого этапа есть e2e-проверка доступности страницы и canonical URL; unit-тесты бизнес-логики будут добавлены вместе с функциональностью на следующих этапах. Перед первым e2e-запуском установите браузер командой `npx playwright install chromium`.

## Структура

- `app/` — маршруты и корневой layout Next.js.
- `src/_pages/`, `src/shared/` — начальные слои Feature-Sliced Design. Новые слои добавляются по реальной потребности.
- `src/shared/config/` — JSON с редактируемым содержимым.
- `public/images/` — изображения для сайта после переноса прототипа.
- `prototype/` — неизменённый исходник для сверки.
- `instructions/` — утверждённые требования, ответы и решения.

## Серверные секреты

Создайте `.env.local` по `.env.example` для локальной разработки. На VPS задавайте переменные окружения процесса Next.js. Значения секретов не должны попадать в Git и в клиентский код. Предоставленный в переписке ключ Telegram нужно перевыпустить до запуска сайта.

Для VPS предусмотрена серверная сборка Next.js (`output: 'standalone'`) за Nginx. Настройка доставки и отправки формы выполняется на следующих согласованных этапах.
