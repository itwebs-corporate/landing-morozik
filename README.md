# Лендинг Никиты Морозика

Next.js-проект для лендинга на основе исходного прототипа в `prototype/`. Требования и решения хранятся в `instructions/`.

## Локальная разработка

Требуется Node.js 20.9+ и npm. Установите зависимости командой `npm ci`, затем запустите `npm run dev`.

Проверки: `npm run lint`, `npm run typecheck`, `npm run build`, `npm test`, `npm run test:e2e`. Перед первым e2e-запуском установите браузер командой `npx playwright install chromium`.

## Структура

- `app/` — маршруты и корневой layout Next.js.
- `src/_pages/home/ui/` — компоненты секций лендинга, `src/_pages/home/model/content/` — их тексты, ссылки и имена изображений в JSON. Для правки текста найдите его в JSON нужной секции.
- `src/shared/config/` — JSON с адресом сайта и SEO-данными.
- `public/images/`, `public/fonts/` — локальные изображения и шрифты.
- `prototype/` — неизменённый исходник для сверки.
- `instructions/` — утверждённые требования, ответы и решения.

## Серверные секреты

Создайте `.env.local` по `.env.example` для локальной разработки. На VPS задавайте переменные окружения процесса Next.js. Значения секретов не должны попадать в Git и в клиентский код. Предоставленный в переписке ключ Telegram нужно перевыпустить до запуска сайта.

Для VPS предусмотрена серверная сборка Next.js (`output: 'standalone'`) за Nginx. Перенесены дизайн, контент и работа модальных окон, меню, кейсов и клиентской проверки форм. Сейчас форма готовит текст для ручной отправки пользователем в Telegram или Email и прямо сообщает, что автоматическая доставка ещё не подключена. Серверная отправка заявки, Яндекс Метрика и публикация юридических страниц относятся к следующим этапам. Текущую промежуточную сборку нельзя публиковать как готовый лендинг.
